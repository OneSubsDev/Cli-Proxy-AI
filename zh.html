指南 · 约 10 分钟 · 一次搞定

在你电脑上运行的 AI 代理

你有 ChatGPT、Claude 或 Gemini 的账号，想把它用在编程工具里 —— 也就是 Claude Code、Codex CLI、Cline 这类帮你写代码的助手。 这个页面带你从头装好，还会照着你选的工具直接把配置生成出来 —— 复制粘贴即可，一条命令都不用敲。

第 1 部分

认识它

什么是 AI 代理？

动手安装之前，先花一分钟弄明白。

每家 AI 公司都讲自己的一套“语言”。为 Claude 写的工具看不懂 ChatGPT 账号，反过来也一样。 平时你有哪家的账号，就只能用哪家的工具。

代理就是一个跑在你电脑上的翻译。工具讲什么语言，它就听什么语言， 再翻译成你手上有账号的那家服务商的语言。两边谁也不用知道对方的存在。

左边是你已经有的东西，右边是你想用的东西。中间的代理把每一对都接起来。

三件要先知道的事

开始之前

它跑在你自己的电脑上。不是网上的服务，别人访问不到。

这不是白嫖 AI 的办法。花的还是你自己在付费的那个账号的额度 —— 只是能在更多工具里用了。

装一次就好。装完之后，开机它就自动跑起来。

你需要准备什么

需要什么说明
一台 Mac 或 Windows 电脑两边的步骤几乎一模一样
一个还能用的 AI 账号ChatGPT Plus/Pro、Claude Pro/Max、Gemini、Kimi 或 Grok
大约 10 分钟最花时间的是等下载
第 2 部分

安装

01下载并安装应用

这个应用叫 EasyCLIProxyAPI，免费、开源。

  1. 打开 github.com/router-for-me/EasyCLIProxyAPI/releases
  2. 往下翻到最新版本的 Assets 一栏
  3. Mac 下载后缀是 .dmg 的文件 · Windows 下载后缀是 .zip 的文件
  4. Mac：打开 .dmg 文件，把应用拖进 Applications 文件夹
    Windows：解压后运行里面的程序
  5. 把应用打开
可以放心

在 Mac 上，这个应用已经通过了 Apple 的公证，可以直接打开， 不会弹出“开发者身份不明”的警告。

02安装核心

你刚装好的应用只是带界面的外壳。真正干活的是核心，需要再点一次把它装上。

  1. 在左边的菜单栏里，点 Version Management
  2. 点安装最新核心版本的按钮
  3. 等几秒钟，直到提示安装完成

03启动代理

  1. 点左边菜单里的 Home
  2. 在 Runtime Control 区域里，点运行按钮
  3. 当 Runtime Status 显示 Running，就成了
以后自动运行

启动一次就够了。以后每次开机，应用都会跟着系统自动启动，你不用再做这一步。

04登录你的账号

这一步是把你手上的 AI 账号接到代理上。

  1. 点左边菜单里的 OAuth
  2. 在 OAuth Sign-In 标签页里，找到对应你账号的那一格
  3. 点 Start Sign-In
  4. 浏览器会自动打开 —— 照平时那样登录就行
  5. 登录成功后，那一格会变成 Completed
屏幕上的名字和你熟悉的不一样

很多人卡在这里。应用里用的是技术上的名字，不是你买的那个产品名：

你有的账号要点的那一格叫
ChatGPTCodex OAuth
ClaudeClaude OAuth
GeminiAntigravity OAuth
KimiKimi OAuth
GrokxAI OAuth

登录多个账号比只登一个好。代理会在它们之间自动轮换， 某个账号用完额度时会自动切到另一个 —— 你不会做到一半被卡住。

查看已保存的账号

切到 Authentication Files 标签页，就能看到代理正在保管的账号列表。 每一行是一个账号；绿色的 active 字样表示可以用。 每行上的 Models 按钮会列出该账号有哪些模型 —— 等下就要用到。

05换掉保护密钥

这一步很短，但别跳过。

重要

这个密钥相当于保护你刚登录的全部 AI 账号的密码。应用预设了一个很好猜的默认密钥 —— 请立刻换掉。

  1. 点左边菜单里的 Advanced Settings
  2. 在 General Settings 标签页里，找到 Authentication Keys 区域
  3. 点 + 按钮生成新密钥，然后把旧的删掉
  4. 把新密钥复制到安全的地方 —— 第 3 部分会用到
别把两种密钥搞混

Authentication Keys —— 填进你的编程工具里。

WebUI Key —— 只用来登录代理自己的管理后台。

06查看用量

不是必须的，但知道自己还剩多少挺有用。

点 Usage 可以看调用次数、用掉的字数和费用估算。 而 OAuth → Quota Lookup 标签页 则会告诉你每个账号还剩多少额度。

第 3 部分

使用

通用规则

所有工具都只要三样东西填对。搞懂这三样，任何工具你都能自己配好。

要填什么它是什么去哪里拿
地址 工具把请求发到这里，而不是直接发到网上 永远是 http://127.0.0.1:8317 —— 只有结尾部分有区别，见下文
密钥 让代理确认来找它的确实是你的那串密码 你在第 05 步生成的密钥
模型名 在已登录的账号里挑用哪个“大脑” OAuth → Authentication Files → Models 按钮

/v1 规则 —— 最容易出错的地方

地址的结尾取决于工具讲哪种“语言”。记住一句话： Anthropic 和 Gemini 不带 /v1，其余都要带。

工具完整地址
Claude Codehttp://127.0.0.1:8317
Gemini CLIhttp://127.0.0.1:8317
Codex CLI · OpenCode · Cline · Continue.dev · Droidhttp://127.0.0.1:8317/v1

写了一个模型，不等于被锁死在它上面

配置里的 model 那一行只是启动时的默认值。 这里所有工具事后都能换模型，大部分还能一次性预先写好多个模型：

工具能否预写多个模型使用中切换
Claude Code能 —— Opus / Sonnet / Haiku / Fable 四个名字可以分别指向四个不同模型/model
Codex CLI能 —— 每套一个 <名字>.config.toml 文件/models · 或 codex -m <名字>
Continue.dev能 —— models 本身是个列表点聊天框底部的模型名
Droid能 —— custom_models 是个数组在切换模型的地方选
OpenCode不需要提前写/models
Cline / Roo Code一次只能一个模型改设置里的 Model ID 那一栏
Gemini CLI一次只能一个模型改环境变量，然后开个新窗口

下面的配置生成器会为支持多模型的工具自动写好多个模型，并说明每种工具怎么切换。

四个容易绊倒人的地方

  • 有哪些模型可用，取决于你登录了哪些账号。没登录 ChatGPT 就调不到 GPT 模型，名字打得再对也没用。每种套餐也不一样 —— Plus 套餐有的模型，Free 套餐不一定有。
  • 改完配置必须开一个新会话。已经开着的工具窗口， 在你关掉重开之前用的还是旧配置。
  • 密钥就是密码。别传到 GitHub 上，也别发到群聊里。
  • 代理必须处于运行状态。工具报 connection refused， 几乎总是因为忘了把应用打开。

遇到问题

现象怎么办
点了运行但没变成 Running 多半是还没装核心。回到第 02 步。
登录完了却看不到账号 浏览器可能拦了弹出窗口。重试一次，浏览器问的时候点允许。 再到 Authentication Files 标签页确认。

提示额度用完 账号额度已经用光了。等它恢复，或者再登录一个账号。

常见问题

需要用命令行吗？

不需要。安装部分只是在带界面的应用里点按钮。配置部分这个页面会帮你生成好， 剩下的就是复制粘贴到对的位置。

会额外花钱吗？

应用是免费的。但它不会凭空变出新的用量 —— 花的还是你在付费的那个账号的额度。

它会把我的数据发到什么奇怪的地方吗？

不会。应用跑在你自己的电脑上，只监听本机地址 127.0.0.1，别的机器连不进来。数据从你的电脑直接发给你登录的那家服务商， 和你直接用它们时一样。

用 ChatGPT 驱动 Claude Code，效果和正版完全一样吗？

不一样。界面和操作是一模一样的，但模型不同，干活的方式就不同 —— 质量和回答风格都会有些偏差。把这看作一种“能用上自己喜欢的工具”的办法， 而不是白嫖 Claude 的办法。

可以同时配好几个工具吗？

可以，而且这正是它的妙处。一个代理同时服务所有工具 —— Claude Code、 Codex CLI 和 OpenCode 都指向 :8317，三个并行跑， 共用你登录的那些账号。

想卸载的话怎么办？

进 Home 点 stop， 然后像卸载其他软件一样把应用删掉。你配置过的那些工具， 在你把加进去的地址和密钥删掉之后，就会恢复原样。

这样用会不会导致我的账号被封？

说实话：有风险。用自动化工具访问订阅制账号，通常超出了服务商使用条款的范围。 个人正常用量下风险较低，但如果多人共用一个账号，或者调用频率明显异常， 风险就会明显上升。用在重要账号上之前请先掂量一下。

这里用到的软件是 CLIProxyAPI 以及它的图形界面版 EasyCLIProxyAPI —— 开源，MIT 许可证， github.com/router-for-me/CLIProxyAPI。 页面中的截图已对私有信息做了模糊处理。 模型列表基于核心版本 v7.2 —— 你的账号可能不同，请始终以应用里 Models 按钮显示的为准。
