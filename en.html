An AI proxy on your machine

You have a ChatGPT, Claude or Gemini account, and you want to use it inside coding tools — the assistants that write code with you, like Claude Code, Codex CLI or Cline. This page walks you through the setup from scratch, then builds the configuration for the tool you pick — copy, paste, no commands to type.

Part 1

Introduction

What is an AI proxy?

One minute of background before you start installing.

Every AI company speaks its own “language”. A tool built for Claude does not understand a ChatGPT account, and the other way round. Normally, whichever account you hold decides which company's tool you are stuck with.

A proxy is a translator running right on your machine. Whatever language a tool speaks, the proxy listens in that language, then translates it into the language of the provider you actually have an account with. Neither side needs to know about the other.

On the left is what you already have. On the right is what you want to use. The proxy in the middle connects every pair.

Three things worth knowing

Before you start

It runs on your machine. It is not an online service, and nobody else can reach it.

It is not a way to get AI for free. You still spend the account you are already paying for — you can just spend it in more tools.

You set it up once. After that it starts on its own every time you boot.

Part 2

Installation

01Download and install the app

The app is called EasyCLIProxyAPI. It is free and open source.

  1. Open github.com/router-for-me/EasyCLIProxyAPI/releases
  2. Scroll down to Assets under the newest release
  3. On a Mac download the .dmg file · on Windows download the .zip file
  4. Mac: open the .dmg and drag the app into your Applications folder
    Windows: unzip it and run the file inside
  5. Open the app
Nothing to worry about

On a Mac this app is notarised by Apple, so it opens straight away, with no “unidentified developer” warning.

02Install the core

The app you just installed is the shell with the interface. The core is the part that does the real work, and you install it with one more click.

  1. In the left-hand menu, click Version Management
  2. Click the button that installs the newest core version
  3. Wait a few seconds until it reports that the install is finished

03Start the proxy

  1. Click Home in the left-hand menu
  2. In the Runtime Control panel, click the run button
  3. When Runtime Status shows Running, you are done
It starts itself from now on

You only do this once. The next time you turn the machine on, the app starts with the system and you can skip this step.

04Sign in to your account

This is the step that connects the AI account you already have to the proxy.

  1. Click OAuth in the left-hand menu
  2. On the OAuth Sign-In tab, find the card for your account
  3. Click Start Sign-In
  4. Your browser opens by itself — sign in the way you normally would
  5. When it finishes, that card switches to Completed
The names on screen are not the names you know

This is where a lot of people pause. The app uses technical names, not the product names you bought:

Signing in with several accounts beats signing in with one. The proxy rotates between them, and when one account runs out of quota it moves to the next — so you are not left stranded half-way through something.

Check the accounts it has saved

Go to the Authentication Files tab to see the accounts the proxy is holding. Each row is one account; a green active means it is ready to use. The Models button on each row lists the models that account can reach — you will need that in a moment.

05Change the access key

A short step, but do not skip it.

Important

This key is the password guarding every AI account you just signed in with. The app ships with an easy-to-guess default — change it now.

  1. Click Advanced Settings in the left-hand menu
  2. On the General Settings tab, find the Authentication Keys panel
  3. Click + to create a new key, then delete the old one
  4. Copy the new key somewhere safe — part 3 needs it
Do not mix up the two keys

Authentication Keys — what you put into your coding tools.

WebUI Key — only for signing in to the proxy's own admin page.

06Track your usage

Not required, but handy for knowing how much you have left.

Click Usage to see call counts, tokens used and an estimated cost. And OAuth → the Quota Lookup tab shows how much allowance each account has left.

Using it

The general rules

Every tool needs exactly three things. Once you understand those three, you can set up any tool yourself.

What to fill inWhat it isWhere to get it
Address Where the tool sends its requests, instead of straight out to the internet Always http://127.0.0.1:8317 — only the ending differs, see below
Key The password that tells the proxy the call really is from you The key you created in step 05
Model name Which “brain” to use out of the accounts you signed in with OAuth → Authentication Files → the Models button

The /v1 rule — the most common mistake

The ending of the address depends on which “language” the tool speaks. Remember one sentence: Anthropic and Gemini take no /v1, everything else does.

Four things that trip people up

  • The models you get are decided by the accounts you signed in with. Without a ChatGPT sign-in you cannot call a GPT model, however correctly you spell the name. Plans differ too — a Plus plan has models a Free plan does not.
  • After editing a config, start a new session. A tool window that is already open keeps using the old config until you close it and open it again.
  • The key is a password. Do not put it on GitHub, do not paste it into a group chat.
  • The proxy has to be running. A tool reporting connection refused is almost always the app not being started.

When something goes wrong

What you seeWhat to do
You click run but it never reaches Running Most likely the core is not installed. Go back to step 02.
You signed in but no account appears Your browser may be blocking the pop-up. Try again and allow it when the browser asks. Check on the Authentication Files tab.
401 The key in the tool does not match the one in Authentication Keys. Compare them character by character.
404 The /v1 ending on the address is wrong. See the table under The general rules.
connection refused The proxy is not running. Open the app, go to Home and start it again.
unknown provider for model … The model name does not belong to any account you signed in with. Check the list behind the Models button, or sign in with the matching account.
It says you are out of quota The account has used up its allowance. Wait for it to reset, or sign in with one more account.

Common questions

Do I have to use the command line?

No. Installing is a matter of clicking buttons in an app with a real interface. The configuration is generated for you on this page; the rest is copy and paste into the right place.

Does it cost extra?

The app is free. But it does not create new usage — you are still spending the allowance of the account you already pay for.

Does it send my data somewhere strange?

No. The app runs on your machine and only listens on the local address 127.0.0.1, which no other machine can reach. Your data goes straight from your machine to the provider you signed in with, just as it would without the proxy.

Is running Claude Code on a ChatGPT account the same as the real thing?

No. The interface and the workflow are identical, but different models work differently — quality and phrasing both drift a little. Treat this as a way to use the tool you like, not a way to get Claude for free.

Can I set up several tools at once?

Yes, and that is the good part. One proxy serves every tool at the same time — Claude Code, Codex CLI and OpenCode can all point at :8317, run side by side, and share the accounts you signed in with.

How do I uninstall it?

Go to Home, click stop, then delete the app like any other software. The tools you configured go back to normal once you remove the address and key you added to them.

Could my account be banned for doing this?

Straight answer: there is a risk. Reaching a subscription account through automated tooling usually falls outside a provider's terms of use. The risk is low for ordinary personal use, but it climbs noticeably if several people share one account or if calls come at an unusual rate. Think it over before using an account you care about.
